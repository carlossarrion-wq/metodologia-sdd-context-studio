# Glosario Corporativo de Naturgy

Términos de nivel grupo. La terminología específica de distribución eléctrica está en el glosario de UFD (bus_05).

| Término | Definición |
|---|---|
| **ATR** | Acceso de Terceros a la Red: derecho de las comercializadoras a usar las redes; también el sistema de mensajes entre distribuidoras y comercializadoras |
| **Autoconsumo** | Generación de energía (normalmente solar) para consumo propio, con o sin vertido de excedentes a la red |
| **Biometano** | Gas renovable obtenido de residuos orgánicos, inyectable en la red de gas |
| **Ciclo combinado** | Central térmica de gas que combina turbina de gas y de vapor; respaldo del sistema eléctrico |
| **CNMC** | Comisión Nacional de los Mercados y la Competencia; regulador energético |
| **CNMV** | Comisión Nacional del Mercado de Valores; supervisor de la Bolsa |
| **Comercializadora** | Empresa que vende energía al cliente final |
| **Comercializadora de referencia** | Comercializadora obligada a ofrecer las tarifas reguladas (PVPC en electricidad, TUR en gas) y el bono social |
| **CSRD** | Directiva europea de información corporativa sobre sostenibilidad |
| **CUPS** | Código Universal del Punto de Suministro; identifica cada punto de luz o gas |
| **Distribuidora** | Empresa que gestiona la red local y lleva la energía hasta el cliente (UFD, Nedgia) |
| **EBITDA** | Resultado bruto de explotación; principal indicador de resultado operativo |
| **Enagás** | Gestor técnico del sistema gasista español |
| **ESG** | Criterios ambientales, sociales y de gobierno corporativo |
| **Free float** | Parte del capital que cotiza libremente en Bolsa |
| **GNL** | Gas natural licuado; gas transportado en barco a –160 °C |
| **Hidrógeno renovable** | Hidrógeno producido por electrólisis con electricidad renovable |
| **Medgaz** | Gasoducto submarino que une Argelia con España (Almería) |
| **MIBGAS** | Mercado ibérico organizado de gas |
| **Mercado libre** | Contratos de energía con precio pactado libremente con la comercializadora |
| **Nedgia** | Distribuidora de gas del grupo Naturgy en España |
| **Naturgy Clientes** | Comercializadora del grupo en el mercado libre |
| **OMIE** | Operador del mercado ibérico de electricidad |
| **Peaje / cargo** | Componentes regulados de la factura por el uso de las redes y costes del sistema |
| **PPA** | Contrato de compraventa de energía a largo plazo (Power Purchase Agreement) |
| **PVPC** | Precio Voluntario para el Pequeño Consumidor; tarifa eléctrica regulada |
| **REE** | Red Eléctrica; operador del sistema eléctrico y gestor de la red de transporte |
| **Retribución regulada** | Ingresos de las redes fijados por el regulador |
| **Separación de actividades (unbundling)** | Independencia obligatoria entre redes y actividades liberalizadas |
| **Sonatrach** | Compañía estatal argelina de hidrocarburos; proveedor y accionista de Naturgy |
| **TUR** | Tarifa de Último Recurso de gas |
| **UFD** | Distribuidora eléctrica del grupo Naturgy |
| **Vulnerable (cliente)** | Cliente protegido por la normativa (bono social, restricciones al corte de suministro) |
