# Funciones Corporativas y Mapa de Procesos

## 1. Funciones corporativas

Dan servicio transversal a todas las áreas de negocio.

| Función | Responsabilidad principal |
|---|---|
| **Finanzas y Control** | Contabilidad, consolidación, tesorería, planificación y control de gestión, fiscalidad |
| **Relación con Inversores** | Comunicación con accionistas y mercados |
| **Jurídico y Cumplimiento** | Asesoría legal, cumplimiento normativo, compliance penal, protección de datos (DPO) |
| **Regulación** | Relación con reguladores, análisis normativo, defensa de la retribución |
| **Personas (RR. HH.)** | Selección, formación, compensación, relaciones laborales |
| **Sistemas y Tecnología (IT/Digital)** | Aplicaciones, infraestructura, cloud, datos, IA, ciberseguridad |
| **Compras y Aprovisionamientos** | Contratación de bienes y servicios, gestión de proveedores |
| **Seguridad, Salud y Medio Ambiente** | Prevención de riesgos, seguridad industrial, impacto ambiental |
| **Sostenibilidad** | Estrategia ESG, reporting no financiero (CSRD) |
| **Comunicación y Marca** | Comunicación interna y externa, marca, relaciones institucionales |
| **Auditoría Interna y Riesgos** | Control interno, gestión de riesgos corporativos |

## 2. Mapa de procesos (nivel 1)

| Tipo | Procesos |
|---|---|
| **Estratégicos** | Planificación estratégica, gestión regulatoria, gestión de riesgos, sostenibilidad |
| **Operativos (negocio)** | Aprovisionamiento y trading de energía · Desarrollo y operación de generación · Planificación, construcción y operación de redes · Conexión de clientes a la red · Captación y contratación de clientes · Facturación y cobro · Atención al cliente y reclamaciones · Mantenimiento y servicios técnicos |
| **Soporte** | Finanzas · Compras · Personas · IT · Jurídico · Gestión documental · Prevención |

## 3. Zonas típicas de mejora con casos de uso sencillos

Casos de uso pequeños (2-6 semanas) que mejoran un proceso concreto:

| Área | Ejemplos de casos de uso |
|---|---|
| **Atención al cliente** | Clasificación automática de correos y formularios; borradores de respuesta a reclamaciones; resumen de historial del cliente para el agente |
| **Back office de contratación / conexión** | Revisión de documentación aportada (completitud, coherencia); extracción de datos de boletines o facturas; alertas de plazos regulatorios |
| **Facturación y cobro** | Detección de anomalías en facturas; explicación de facturas al cliente; priorización de gestión de impagos (respetando protección del vulnerable) |
| **Compras** | Análisis comparativo de ofertas; extracción de cláusulas de contratos; homologación de proveedores |
| **Finanzas** | Conciliaciones; preparación de informes de gestión; revisión de facturas de proveedores |
| **Jurídico y Regulación** | Resumen de normativa nueva y su impacto; búsqueda en el corpus normativo interno |
| **Personas** | Asistente de políticas internas; cribado de consultas al departamento |
| **Operaciones** | Resumen de partes de trabajo; búsqueda en manuales técnicos; informes de incidencias |

### Criterios para elegir un buen caso de uso

- Proceso repetitivo, con volumen y reglas conocidas.
- Datos disponibles y de calidad suficiente.
- Beneficio medible (horas, plazo, errores, satisfacción).
- Riesgo bajo: sin decisiones automáticas con efectos significativos sobre personas (ver NORM-IA-001).
- Un responsable de negocio comprometido (Product Owner).
